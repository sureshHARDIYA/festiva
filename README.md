# Festiva

**Status: concept and architecture only. No implementation approved.**

Festiva is a proposed zero-runtime-dependency TypeScript animation engine for seasonal, weather and celebration effects on existing websites. The intended experience is premium, brand-aware, subtle and interactive, rather than a full-screen decorative cartoon.

Read [knowledge/README.md](knowledge/README.md) for the current decisions and open questions.

**Not yet approved:** final visual style, Christmas interaction design, implementation, npm package name and publication.
